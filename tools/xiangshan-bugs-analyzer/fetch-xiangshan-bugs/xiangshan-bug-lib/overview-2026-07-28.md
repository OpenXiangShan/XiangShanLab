# XiangShan Bug Library Overview

> Canonical entry point for this bug library.

## Scope

- Repository: `OpenXiangShan/XiangShan`
- Issues collected: `105`
- PRs collected: `74`
- Issue/PR lookup: [issue-index.md](issue-index.md), [pr-index.md](pr-index.md)
- Cause summary: [bug-cause-summary.md](bug-cause-summary.md)

## What matters

- Use the `Branch` column first. Kunminghu data splits between `kunminghu-v2` and `kunminghu-v3`.
- Use the `Commit` column only when a concrete SHA is present in the source record or report body.
- `issue-index.md` is the quick lookup table for issue triage.
- `pr-index.md` is the quick lookup table for PR triage.
- `bug-cause-summary.md` groups items by heuristic cause, not final root cause.

## Current signal

The current dataset is dominated by:

- architecture-visible issues around CSR, trap handling, PMP/PMA, RVV state, and difftest mismatches
- microarchitectural issues around load/store deadlock, redirect/kill cleanup, replay, and predictor disable handling
- PRs on `kunminghu-v3`, with `kunminghu-v2` still present in the historical issue set

## Navigation

1. Start with [issue-index.md](issue-index.md) or [pr-index.md](pr-index.md).
2. Use [bug-cause-summary.md](bug-cause-summary.md) for coarse clustering.
3. Use the raw JSONL files only when you need evidence details.
4. Treat the long narrative reports below as legacy summaries; they are kept only as pointers to the canonical files above.
