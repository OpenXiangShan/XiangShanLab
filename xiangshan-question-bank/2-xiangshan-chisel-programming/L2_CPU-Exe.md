# L4 CPU-Exe 方向 Chisel Programming 题目

## 统一题目格式

每题需提交设计文档、验证计划、Chisel 代码、Verilog 代码、黑盒参考模型、白盒参考模型、验证代码、Coverage、仿真结果、综合结果、Critical Path、Area、时序分析和后仿结果。YAML 需描述向量参数、元素宽度、LMUL、测试约束和评分项。

## 题目 1：LMUL = 1/2/4/8 Compress 指令的加速实现

- 功能需求：实现向量 compress 数据压缩路径，根据 mask 将有效元素紧凑写入目标向量，支持 LMUL 1/2/4/8 和多种 SEW。
- 输出需求：输出压缩后元素、写掩码、元素计数、异常或非法配置标志。
- 难度级别：L4 中级。
- 预期工期：1 周。
- 交付物清单：设计文档、RTL、ISA 参考模型、mask 边界测试、Coverage、综合/STA 报告。

## 题目 2：LMUL = 1/2/4/8 Scatter 指令的加速实现

- 功能需求：实现向量 scatter 地址生成与请求发射，支持非连续地址、mask、元素宽度、异常回报和访存乱序响应整理。
- 输出需求：输出访存请求、完成状态、异常元素索引和性能计数器。
- 难度级别：L4 中级。
- 预期工期：1 周。
- 交付物清单：架构文档、Chisel/Verilog、指令参考模型、访存随机测试、Coverage、综合报告。

## 题目 3：LMUL = 1/2/4/8 Gather 指令的加速实现

- 功能需求：实现向量 gather 地址生成、请求跟踪、响应重排和目标寄存器写回，支持 mask 和不同 SEW。
- 输出需求：输出访存请求、重排缓冲状态、写回数据、异常状态。
- 难度级别：L4 中级。
- 预期工期：1 周。
- 交付物清单：设计文档、RTL、参考模型、乱序响应测试、Coverage、综合/STA/后仿报告。
