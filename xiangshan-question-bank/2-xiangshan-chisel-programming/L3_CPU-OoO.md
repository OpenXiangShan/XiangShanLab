# L5 CPU-OoO 方向 Chisel Programming 题目

## 统一题目格式

每题需提交设计文档、验证计划、Chisel 代码、Verilog 代码、黑盒参考模型、白盒参考模型、验证代码、Coverage、仿真结果、综合结果、Critical Path、Area、时序分析和后仿结果。YAML 需描述发射宽度、执行单元、端口约束、测试场景和评分项。

## 题目 1：为三个执行单元设计分布式 Issue Queue

- 功能需求：为整数、浮点、访存三个执行单元分别实现 Issue Queue，支持 dispatch 入队、操作数唤醒、选择发射、flush 和队列容量反馈。
- 输出需求：输出各队列发射指令、阻塞原因、唤醒命中、队列占用。
- 难度级别：L5 高级。
- 预期工期：1-2 周。
- 交付物清单：微架构文档、RTL、调度参考模型、相关性与公平性测试、Coverage、综合/STA/后仿报告。

## 题目 2：为三个执行单元设计集中式 Issue Queue

- 功能需求：实现统一 Issue Queue，按执行单元能力进行选择与仲裁，支持多源唤醒、多路发射、年龄优先和端口冲突处理。
- 输出需求：输出发射选择、仲裁状态、唤醒矩阵、阻塞统计。
- 难度级别：L5 高级。
- 预期工期：1-2 周。
- 交付物清单：架构文档、Chisel/Verilog、周期级模型、多执行单元测试、Coverage、综合报告。

## 题目 3：PRF 多 bank 设计

- 功能需求：实现多 bank 物理寄存器堆，支持多读多写、bank conflict 检测、旁路、写优先/读优先策略和仲裁。
- 输出需求：输出读数据、冲突信息、bank 访问统计、旁路命中。
- 难度级别：L5 高级。
- 预期工期：1-2 周。
- 交付物清单：设计文档、RTL、寄存器堆参考模型、冲突随机测试、Coverage、综合/STA/后仿报告。
