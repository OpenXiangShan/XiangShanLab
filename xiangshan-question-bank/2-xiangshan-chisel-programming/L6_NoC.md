# L6 NoC 方向 Chisel Programming 题目

## 统一题目格式

每题需提交设计文档、验证计划、Chisel 代码、Verilog 代码、系统级黑盒参考模型、周期级白盒参考模型、验证代码、Coverage、仿真结果、综合结果、Critical Path、Area、时序分析和后仿结果。YAML 需描述网络拓扑、节点数量、路由策略、流控协议、流量模型、测试场景和评分项。

通用交付物清单：
- 设计文档：拓扑结构、router 微架构、flit 格式、路由算法、流控、仲裁、公平性和死锁避免。
- 设计代码：Chisel RTL、生成 Verilog、参数配置、构建和仿真脚本。
- 参考模型：系统级网络黑盒模型、周期级 router/link 白盒模型。
- 验证代码：定向流量、随机流量、拥塞场景、Coverage 和断言。
- 结果报告：仿真日志、吞吐/延迟统计、综合结果、Critical Path、Area、STA 和后仿结果。

## 题目 1：2x2 Mesh NoC

- 功能需求：实现 2x2 Mesh NoC，包含路由器、链路、XY 路由、流控、仲裁和死锁避免说明。
- 输出需求：输出 flit 传输、路由状态、阻塞统计、端到端延迟。
- 难度级别：L6 实践。
- 预期工期：2-3 周。
- 交付物清单：NoC 架构文档、Chisel/Verilog、网络参考模型、流量测试、Coverage、综合/STA/后仿报告。

## 题目 2：2x2 Ring NoC

- 功能需求：实现 2x2 Ring NoC，支持单向或双向环、注入/弹出、路由选择、流控和公平仲裁。
- 输出需求：输出 flit 传输、ring 占用、仲裁状态、延迟/吞吐统计。
- 难度级别：L6 实践。
- 预期工期：2-3 周。
- 交付物清单：设计文档、Chisel/Verilog、网络模型、热点/均匀流量测试、Coverage、综合/STA/后仿报告。
