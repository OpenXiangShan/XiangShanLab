# L4 CPU-OoO 方向 Chisel Programming 题目

## 统一题目格式

每题需提交设计文档、验证计划、Chisel 代码、Verilog 代码、黑盒参考模型、白盒参考模型、验证代码、Coverage、仿真结果、综合结果、Critical Path、Area、时序分析和后仿结果。YAML 需描述乱序结构参数、端口数量、测试约束和评分项。

## 题目 1：Rename Table 实现

- 功能需求：实现逻辑寄存器到物理寄存器的映射表，支持多路读写、重命名、提交、分支快照和误预测恢复。
- 输出需求：输出源物理寄存器、旧目的物理寄存器、快照恢复状态和旁路命中信息。
- 难度级别：L4 中级。
- 预期工期：1 周。
- 交付物清单：设计文档、RTL、重命名模型、快照/回滚测试、Coverage、综合与后仿报告。

## 题目 2：Freelist 实现

- 功能需求：实现物理寄存器空闲表，支持多路分配、多路释放、分支快照、回滚和容量检测。
- 输出需求：输出分配物理寄存器、可分配数量、空/满状态和快照状态。
- 难度级别：L4 中级。
- 预期工期：1 周。
- 交付物清单：设计文档、Chisel/Verilog、队列/bitmap 参考模型、随机分配释放测试、Coverage、综合/STA 报告。

## 题目 3：Tomasulo 算法实现

- 功能需求：实现简化 Tomasulo 调度核心，包含保留站、寄存器重命名、操作数唤醒、执行完成广播和写回。
- 输出需求：输出 issue/execute/writeback 事件、保留站状态、寄存器映射状态。
- 难度级别：L4 中级。
- 预期工期：1 周。
- 交付物清单：架构文档、RTL、周期级调度模型、相关性测试、Coverage、综合与后仿报告。

## 题目 4：Scoreboard 算法实现

- 功能需求：实现 Scoreboard 调度与冒险管理，跟踪功能单元占用、寄存器读写相关、发射许可和写回释放。
- 输出需求：输出指令发射许可、阻塞原因、功能单元状态和寄存器 busy 状态。
- 难度级别：L4 中级。
- 预期工期：1 周。
- 交付物清单：设计文档、Chisel/Verilog、scoreboard 参考模型、RAW/WAW/WAR 测试、Coverage、综合报告。
