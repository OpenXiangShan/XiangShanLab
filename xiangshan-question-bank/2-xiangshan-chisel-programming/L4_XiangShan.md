# L6 香山方向 Chisel Programming 题目

## 统一题目格式

每题需在香山代码框架内完成设计、集成和验证。提交内容包括设计文档、验证计划、Chisel 修改、生成 Verilog、系统级黑盒参考模型、周期级白盒参考模型、验证代码、Coverage、仿真结果、综合结果、Critical Path、Area、时序分析和后仿结果。YAML 需描述改动模块、配置开关、ISA/微架构约束、测试列表和评分项。

通用交付物清单：
- 设计文档：背景、接口、改动路径、兼容性、异常/flush/redirect 处理。
- 设计代码：香山 Chisel 修改、配置项、生成 Verilog、必要脚本。
- 参考模型：功能参考模型、周期级白盒模型或断言模型。
- 验证代码：单元测试、微架构测试、必要的 ISA/difftest 测试、Coverage。
- 结果报告：仿真、综合、Critical Path、Area、STA、后仿与性能对比。

## 题目 1：为新增 CSR 做 rename

- 功能需求：为新增 CSR 设计 rename 路径，处理 CSR 读写相关、提交更新、flush 回滚和异常精确性。
- 输出需求：输出 CSR rename 映射、依赖检查结果、提交/回滚事件。
- 难度级别：L6 实践。
- 预期工期：2-3 周。
- 交付物清单：CSR 设计文档、Chisel 修改、参考模型、CSR 指令测试、Coverage、综合/STA 报告。
