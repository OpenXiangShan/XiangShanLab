# L1 CPU/xPU 方向 Chisel Programming 题目

## 统一题目格式

每题需提交设计文档、Chisel 代码、生成 Verilog、系统级黑盒参考模型、周期级白盒参考模型、验证代码、Coverage、仿真结果、综合数据、Critical Path、Area、时序分析和后仿结果。题目配置、约束、评分项和测试列表需用 YAML 描述。

交付物清单：
- `docs/`：设计文档、验证计划、结果报告。
- `src/`：Chisel RTL 与生成 Verilog。
- `model/`：黑盒参考模型与白盒周期模型。
- `verify/`：测试、约束、Coverage。
- `reports/`：仿真、综合、STA、后仿报告。

## 题目 1：2-bit 饱和分支预测器

- 功能需求：实现基于 2-bit 饱和计数器的分支预测表，支持按 PC 查询预测结果，并根据实际跳转结果更新计数器；需要处理表项初始化、别名冲突和同周期查询/更新冲突。
- 输出需求：输出 `taken` 预测、命中/有效状态、更新后的计数器状态和调试可观测信息。
- 难度级别：L1 初级。
- 预期工期：2-3 天。
- 验收关注点：饱和加减边界、冷启动行为、连续训练后的预测收敛、同地址与不同地址交错访问。

## 题目 2：LRU 替换算法

- 功能需求：实现参数化 N 路组相联 LRU 替换状态维护，支持访问一路后更新年龄关系，并在需要替换时给出 victim way。
- 输出需求：输出 victim way、每组 LRU 状态、非法输入检测或断言结果。
- 难度级别：L1 初级。
- 预期工期：2-3 天。
- 验收关注点：全排列年龄更新、重复命中、reset 后 victim 选择、参数化路数扩展。

## 题目 3：PLRU 替换算法

- 功能需求：实现树形 PLRU，支持 4/8/16 路参数化配置；命中访问后更新路径方向位，替换时沿树选择 victim。
- 输出需求：输出 victim way、PLRU 树状态、访问更新后的状态。
- 难度级别：L1 初级。
- 预期工期：2-3 天。
- 验收关注点：树节点编码、各 way 访问覆盖、reset 后固定选择、与软件 PLRU 模型一致性。

## 题目 4：前导零检测

- 功能需求：实现参数化位宽前导零检测器，支持输入为 0 时返回全宽计数和 zero 标志；可采用分层优先编码或并行树结构。
- 输出需求：输出前导零数量、输入为零标志、可选首个 1 的位置。
- 难度级别：L1 初级。
- 预期工期：2-3 天。
- 验收关注点：全 0、最高位为 1、最低位为 1、随机输入与软件模型一致。

## 题目 5：LFSR 线性反馈移位寄存器

- 功能需求：实现可配置多项式和种子的 LFSR，支持 enable、seed load、next 状态生成，可选择 Fibonacci 或 Galois 结构。
- 输出需求：输出当前随机序列值、有效标志、可选周期统计信息。
- 难度级别：L1 初级。
- 预期工期：2-3 天。
- 验收关注点：禁止全 0 锁死、指定多项式序列一致、seed 重载、连续 enable/disable。

## 题目 6：Age Matrix 算法实现

- 功能需求：实现乱序结构中条目年龄矩阵，支持多端口分配、释放、flush 和任意两条目的新老关系比较。
- 输出需求：输出 older-than 比较结果、有效位矩阵、分配/释放后的矩阵状态。
- 难度级别：L1 初级。
- 预期工期：2-3 天。
- 验收关注点：同周期多分配年龄顺序、释放后状态清理、flush 后清空、矩阵反对称性质。

## 题目 7：Booth2/4/8/2n 算法实现

- 功能需求：实现参数化 Booth 乘法编码器和部分积生成器，支持有符号/无符号乘法，至少覆盖 Booth2、Booth4、Booth8 中两种配置。
- 输出需求：输出部分积、符号修正项、最终乘积和中间调试信号。
- 难度级别：L1 初级。
- 预期工期：2-3 天。
- 验收关注点：负数乘法、边界值、符号扩展、不同 Booth radix 与软件模型一致。

## 题目 8：4/8/16 个部分积 Wallace-tree 实现

- 功能需求：实现参数化 Wallace Tree 压缩网络，将多个部分积压缩为两行结果，并接入最终加法器得到乘法结果。
- 输出需求：输出每层压缩结果、最终 sum/carry、乘积结果。
- 难度级别：L1 初级。
- 预期工期：2-3 天。
- 验收关注点：压缩层级正确性、位宽增长、随机乘法回归、综合后关键路径。

## 题目 9：Cache 直接映射/全相联/组相联实现

- 功能需求：实现参数化 Cache，支持直接映射、全相联和组相联配置；包含 tag/data/valid 管理、命中判断、miss refill 和替换策略。
- 输出需求：输出 CPU 响应、内存请求、命中/未命中状态、替换 way 和性能计数器。
- 难度级别：L1 初级。
- 预期工期：2-3 天。
- 验收关注点：地址拆分、refill 流程、替换一致性、不同关联度配置回归。

## 题目 10：Cache Write Through / Write Back 实现

- 功能需求：在 Cache 中实现 write-through 与 write-back 两种写策略，支持 dirty bit、写命中、写未命中分配策略和回写流程。
- 输出需求：输出写响应、内存写请求、dirty 状态、writeback 事务信息。
- 难度级别：L1 初级。
- 预期工期：2-3 天。
- 验收关注点：dirty 行替换、连续写同一行、读写交错、内存最终一致性。

## 题目 11：乘加器

- 功能需求：实现 `a * b + c` 乘加单元，支持参数化位宽、有符号/无符号模式和可选流水线级数。
- 输出需求：输出乘加结果、valid/ready 握手、溢出或截断标志。
- 难度级别：L1 初级。
- 预期工期：2-3 天。
- 验收关注点：符号组合、流水线 valid 对齐、边界值、综合频率与面积。

## 题目 12：简易计算器

- 功能需求：实现支持加、减、乘、除或移位等基本运算的计算器，包含命令解析、操作数寄存、执行状态机和异常处理。
- 输出需求：输出运算结果、busy/done、非法操作和除零异常。
- 难度级别：L1 初级。
- 预期工期：2-3 天。
- 验收关注点：多操作连续提交、异常路径、状态机跳转、参考模型一致性。

## 题目 13：矩阵转置

- 功能需求：实现参数化矩阵转置模块，支持流式输入输出或 SRAM 缓冲方式；矩阵尺寸至少支持 4x4 和 8x8。
- 输出需求：输出转置后的矩阵流、valid/ready、地址访问轨迹。
- 难度级别：L1 初级。
- 预期工期：2-3 天。
- 验收关注点：行列地址映射、背压处理、非满速输入输出、矩阵边界。

## 题目 14：矩阵乘法器实现

- 功能需求：实现小规模整数矩阵乘法器，支持参数化 M/N/K 和元素位宽，可采用 MAC 阵列或复用乘加单元。
- 输出需求：输出结果矩阵、计算完成信号、内部计数器和访存请求。
- 难度级别：L1 初级。
- 预期工期：2-3 天。
- 验收关注点：累加位宽、访存顺序、吞吐/面积取舍、随机矩阵比对。

## 题目 15：Hash 算法实现

- 功能需求：实现一种硬件友好的 Hash 算法，例如 CRC、FNV、MurmurHash 简化版或 Toeplitz Hash；支持流式输入和参数化数据宽度。
- 输出需求：输出 hash 值、输入消费握手、packet end 或 flush 后结果有效。
- 难度级别：L1 初级。
- 预期工期：2-3 天。
- 验收关注点：分片输入一致性、初始种子、空消息、随机数据回归。

## 题目 16：冒泡排序

- 功能需求：实现固定长度或参数化长度的冒泡排序硬件，支持批量装载、逐轮比较交换和排序完成输出。
- 输出需求：输出有序数组、done、当前轮次和比较交换状态。
- 难度级别：L1 初级。
- 预期工期：2-3 天。
- 验收关注点：升序/降序配置、重复元素、已排序和逆序输入、周期级模型一致。

## 题目 17：最小公倍数

- 功能需求：实现最小公倍数计算单元，可基于 GCD 欧几里得算法，支持启动/完成握手、除零或输入为 0 的定义处理。
- 输出需求：输出 LCM、busy/done、GCD 中间结果、异常标志。
- 难度级别：L1 初级。
- 预期工期：2-3 天。
- 验收关注点：互质数、相同数、含 0 输入、大数溢出或截断策略。

## 题目 18：红绿灯控制器

- 功能需求：实现参数化红绿灯控制器，支持主路/支路状态切换、绿灯/黄灯/红灯持续周期配置，以及复位后的确定初始状态。
- 输出需求：输出各方向灯色状态、当前 FSM 状态、倒计时或阶段计数器、异常配置标志。
- 难度级别：L1 初级。
- 预期工期：2-3 天。
- 验收关注点：状态机跳转、计数边界、复位行为、连续运行周期与参考模型一致。

## 题目 19：PRLU 实现

- 功能需求：实现参数化 PRLU 模块，支持输入数据位宽、通道数量和斜率参数配置，可用于轻量级神经网络激活函数或数据通路非线性处理。
- 输出需求：输出激活结果、valid/ready 握手、符号判断结果和中间乘加或移位调试信号。
- 难度级别：L1 初级。
- 预期工期：2-3 天。
- 验收关注点：正负输入分支、斜率量化误差、边界值、流水线 valid 对齐、软件模型一致性。

## 题目 20：Gray Code 队列状态判断

- 功能需求：实现基于 Gray code 指针的队列 full、empty、almost full 和 almost empty 判断逻辑，覆盖同步时钟队列和异步时钟 FIFO 两种场景。
- 输出需求：输出读写指针、Gray code 指针、同步后的跨时钟域指针、full/empty/almost 状态。
- 难度级别：L1 初级。
- 预期工期：2-3 天。
- 验收关注点：二进制/Gray code 转换、指针回卷、almost 阈值配置、跨时钟域同步、随机读写回归。

## 题目 21：AXI3 双主仲裁 Crossbar

- 功能需求：实现 AXI3 2-to-1 Crossbar，连接两个主设备和一个从设备；两个主设备事务 ID 范围不重叠，支持 AR/R/AW/W/B 五个通道独立握手。
- 输出需求：输出从设备侧 AXI 请求、两个主设备侧响应、仲裁选择、burst 锁定状态和事务 ID 路由信息。
- 难度级别：L1 中级。
- 预期工期：2-3 天。
- 验收关注点：读写并发、burst 末拍释放、请求通道锁定式仲裁、响应按 ID 返回、一侧持续请求时另一侧不饥饿。

## 题目 22：多端口环形队列

- 功能需求：实现通用环形队列模块，队列深度为 8 或 16 且为 2 的幂；支持每拍最多 4 路入队、最多 3 路出队，并提供按索引随机读接口。
- 输出需求：输出出队数据、empty、full、count、头尾指针、随机读数据和 flush 后状态。
- 难度级别：L1 中级。
- 预期工期：2-3 天。
- 验收关注点：同拍多入队/多出队、头尾指针回卷、flush 清空、不连续输入端口处理、空队列和满队列边界。

## 题目 23：取指缓冲 IBuffer

- 功能需求：实现面向处理器前端的指令缓冲模块，前端每拍最多输入 4 条指令，后端每拍最多消费 3 条指令；每条指令携带指令字、PC 和元信息。
- 输出需求：输出后端指令流、valid/ready 握手、缓冲占用数、取指块边界信息和 redirect 清空状态。
- 难度级别：L1 中级。
- 预期工期：2-3 天。
- 验收关注点：块状入队、后端 redirect 清空、多路 ready 传播、前端/后端不同吞吐、端口顺序约束和边界回归。
