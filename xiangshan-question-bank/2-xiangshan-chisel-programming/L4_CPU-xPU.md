# L4 CPU/xPU 方向 Chisel Programming 题目

## 统一题目格式

每题需提交设计文档、验证计划、Chisel 代码、Verilog 代码、黑盒参考模型、白盒参考模型、验证代码、Coverage、仿真结果、综合结果、Critical Path、Area、时序分析和后仿结果。YAML 需描述数据格式、舍入模式、流水线参数、测试约束和评分项。

## 题目 1：Near-Round 浮点加法器实现

- 功能需求：实现近路径浮点加法器，覆盖指数接近时的尾数对齐、加减、规格化、舍入和异常标志。
- 输出需求：输出浮点结果、异常标志、舍入信息、流水线 valid。
- 难度级别：L4 中级。
- 预期工期：1 周。
- 交付物清单：设计文档、RTL、SoftFloat 或等价模型比对、边界测试、Coverage、综合/STA 报告。

## 题目 2：浮点转整数算法实现

- 功能需求：实现 FP32 或 FP64 到整数转换，支持舍入模式、溢出、NaN、无穷和符号处理。
- 输出需求：输出整数结果、invalid/inexact/overflow 等异常标志。
- 难度级别：L4 中级。
- 预期工期：1 周。
- 交付物清单：设计文档、Chisel/Verilog、参考模型、特殊值测试、Coverage、综合与后仿报告。

## 题目 3：整数转浮点算法实现

- 功能需求：实现整数到 FP32 或 FP64 转换，支持符号、前导零检测、指数生成、尾数舍入和异常标志。
- 输出需求：输出浮点结果、舍入信息、异常标志。
- 难度级别：L4 中级。
- 预期工期：1 周。
- 交付物清单：设计文档、RTL、参考模型、随机整数测试、Coverage、综合报告。

## 题目 4：流水线乘法器

- 功能需求：实现参数化流水线整数乘法器，支持有符号/无符号乘法、可配置延迟和 valid/ready 背压。
- 输出需求：输出乘积、流水级 valid、stall/flush 状态。
- 难度级别：L4 中级。
- 预期工期：1 周。
- 交付物清单：设计文档、Chisel/Verilog、周期模型、背压测试、Coverage、Critical Path 与 Area 报告。

## 题目 5：矩阵乘加器实现

- 功能需求：实现矩阵乘加 `D = A * B + C`，支持可配置矩阵尺寸、数据位宽、MAC 数量和片上缓冲。
- 输出需求：输出结果矩阵、访存事务、计算进度、性能计数器。
- 难度级别：L4 中级。
- 预期工期：1 周。
- 交付物清单：架构文档、RTL、Python/Scala 模型、矩阵随机测试、Coverage、综合/STA/后仿报告。

## 题目 6：FFT 算法实现

- 功能需求：实现固定点 FFT，支持参数化点数、蝶形运算、旋转因子 ROM、缩放/饱和策略和流式输入输出。
- 输出需求：输出频域结果、valid/ready、溢出/饱和标志、阶段状态。
- 难度级别：L4 中级。
- 预期工期：1 周。
- 交付物清单：设计文档、Chisel/Verilog、数学参考模型、误差分析、Coverage、综合报告。

## 题目 7：NTT 算法实现

- 功能需求：实现数论变换 NTT，支持模乘、模加减、蝶形网络、旋转因子表和参数化点数。
- 输出需求：输出变换结果、模运算状态、阶段计数和错误检测。
- 难度级别：L4 中级。
- 预期工期：1 周。
- 交付物清单：设计文档、RTL、软件 NTT 模型、随机多项式测试、Coverage、综合/STA 报告。
