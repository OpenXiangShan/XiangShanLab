# L5 CPU-Predictor 方向 Chisel Programming 题目

## 统一题目格式

每题需提交设计文档、验证计划、Chisel 代码、Verilog 代码、黑盒参考模型、白盒参考模型、验证代码、Coverage、仿真结果、综合结果、Critical Path、Area、时序分析和后仿结果。YAML 需描述预测表规模、trace 输入、训练/回滚约束和评分项。

## 题目 1：Last-Value Predictor 访存值预测算法实现

- 功能需求：实现基于 PC 的 Last-Value Predictor，记录历史 load 值、置信度和验证结果，支持预测、训练、失效和错误恢复。
- 输出需求：输出预测值、置信度、命中状态、误预测事件和统计计数器。
- 难度级别：L5 高级。
- 预期工期：1-2 周。
- 交付物清单：设计文档、RTL、trace 参考模型、值预测测试、Coverage、综合/STA 报告。

## 题目 2：2-level LVP/Stride 访存值预测算法实现

- 功能需求：实现两级值预测结构，结合 last value 与 stride 模式，支持模式选择、置信度更新和预测验证。
- 输出需求：输出预测值、预测类型、置信度变化、错误恢复信息。
- 难度级别：L5 高级。
- 预期工期：1-2 周。
- 交付物清单：架构文档、RTL、参考模型、混合 trace 测试、Coverage、综合报告。

## 题目 3：gDiff 全局步幅访存值预测算法实现

- 功能需求：实现基于全局差分历史的值预测器，维护全局 delta 序列、按 PC 匹配模式并预测下一值。
- 输出需求：输出预测值、delta 匹配状态、置信度和训练事件。
- 难度级别：L5 高级。
- 预期工期：1-2 周。
- 交付物清单：设计文档、Chisel/Verilog、算法模型、trace 回归、Coverage、综合/STA 报告。

## 题目 4：Path-based Stride 访存值预测算法实现

- 功能需求：实现结合控制流 path history 的 stride 值预测器，按 PC 与路径上下文索引预测表并训练 stride。
- 输出需求：输出预测值、路径索引、置信度、误预测恢复状态。
- 难度级别：L5 高级。
- 预期工期：1-2 周。
- 交付物清单：设计文档、RTL、路径 trace 模型、上下文冲突测试、Coverage、综合报告。

## 题目 5：D-FSM 访存值预测算法实现

- 功能需求：实现基于有限状态机模式识别的值预测器，跟踪重复值序列或 delta 序列并进行状态转移预测。
- 输出需求：输出预测值、FSM 状态、模式命中、训练事件。
- 难度级别：L5 高级。
- 预期工期：1-2 周。
- 交付物清单：算法文档、RTL、周期参考模型、模式 trace 测试、Coverage、综合/STA 报告。

## 题目 6：ML-based 值预测算法实现

- 功能需求：实现 ANN/SVM/RF 中一种简化硬件可实现值预测器，明确特征提取、量化、模型存储、推理流水和训练方式。
- 输出需求：输出预测值、模型置信度、特征向量、推理延迟和资源统计。
- 难度级别：L5 高级。
- 预期工期：1-2 周。
- 交付物清单：模型文档、RTL、离线训练脚本或固定模型、trace 测试、Coverage、综合/STA/后仿报告。
