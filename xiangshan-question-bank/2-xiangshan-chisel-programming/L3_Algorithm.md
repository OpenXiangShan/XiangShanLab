# L5 CPU/xPU 方向 Chisel Programming 题目

## 统一题目格式

每题需提交设计文档、验证计划、Chisel 代码、Verilog 代码、黑盒参考模型、白盒参考模型、验证代码、Coverage、仿真结果、综合结果、Critical Path、Area、时序分析和后仿结果。YAML 需描述算法参数、数据格式、流水线配置、测试约束和评分项。

## 题目 1：SRT2/4/8/16/32/64 除法器算法实现

- 功能需求：实现可选 radix 的 SRT 除法器，支持商 digit 选择、余数迭代、规格化、符号处理和异常处理。
- 输出需求：输出商、余数、迭代状态、异常标志和延迟统计。
- 难度级别：L5 高级。
- 预期工期：1-2 周。
- 交付物清单：算法文档、RTL、数学参考模型、边界随机测试、Coverage、综合/STA/后仿报告。

## 题目 2：SRT2/4/8/16/32/64 开方器算法实现

- 功能需求：实现可选 radix 的 SRT 开方器，支持部分余数迭代、结果 digit 选择、规格化和舍入。
- 输出需求：输出平方根、余数、迭代过程、异常或非法输入标志。
- 难度级别：L5 高级。
- 预期工期：1-2 周。
- 交付物清单：设计文档、Chisel/Verilog、参考模型、精度测试、Coverage、综合报告。

## 题目 3：SRT2/4/8/16/32/64 复用除法开方器实现

- 功能需求：设计复用数据通路，同时支持除法和开方，处理共享迭代单元、模式切换、资源仲裁和异常。
- 输出需求：输出除法/开方结果、模式状态、共享资源占用、异常标志。
- 难度级别：L5 高级。
- 预期工期：1-2 周。
- 交付物清单：微架构文档、RTL、统一参考模型、混合操作测试、Coverage、综合/STA/后仿报告。

## 题目 4：随机数生成器

- 功能需求：实现硬件随机或伪随机数生成器，可选 LFSR、xoshiro、CTR-DRBG 简化结构或熵源后处理模型，支持 seed、reseed 和健康检测。
- 输出需求：输出随机数、valid、健康检测状态、统计测试结果。
- 难度级别：L5 高级。
- 预期工期：1-2 周。
- 交付物清单：设计文档、RTL、统计参考模型、随机性测试、Coverage、综合报告。

## 题目 5：RSA 算法实现

- 功能需求：实现 RSA 模幂核心，支持大整数模乘、Montgomery 乘法、指数扫描、密钥/消息加载和完成握手。
- 输出需求：输出模幂结果、运算状态、错误标志、性能计数器。
- 难度级别：L5 高级。
- 预期工期：1-2 周。
- 交付物清单：架构文档、Chisel/Verilog、密码学参考模型、标准向量测试、Coverage、综合/STA 报告。

## 题目 6：AES 算法实现

- 功能需求：实现 AES-128 加密或加解密核心，包含 SubBytes、ShiftRows、MixColumns、AddRoundKey 和 key schedule。
- 输出需求：输出密文/明文、ready/valid、轮状态、错误标志。
- 难度级别：L5 高级。
- 预期工期：1-2 周。
- 交付物清单：设计文档、RTL、标准 AES 参考模型、NIST 向量测试、Coverage、综合/STA/后仿报告。

## 题目 7：SHA 算法实现

- 功能需求：实现 SHA-256 或 SHA-3 核心，支持消息分块、填充、压缩函数迭代和 digest 输出。
- 输出需求：输出 digest、block 消费握手、轮状态、完成标志。
- 难度级别：L5 高级。
- 预期工期：1-2 周。
- 交付物清单：设计文档、RTL、哈希参考模型、标准向量测试、Coverage、综合报告。

## 题目 8：SM 算法实现

- 功能需求：实现一种国密算法硬件核心，例如 SM3 或 SM4，支持标准轮函数、密钥扩展、分块输入和结果输出。
- 输出需求：输出摘要或密文、状态机状态、错误标志、性能计数器。
- 难度级别：L5 高级。
- 预期工期：1-2 周。
- 交付物清单：设计文档、Chisel/Verilog、标准参考模型、测试向量、Coverage、综合/STA 报告。
