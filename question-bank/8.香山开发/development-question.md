2. **AI开发**
 > 点积（Dot Product）是深度学习模型的核心计算内核，在推荐系统、大语言模型（LLM）等AI应用中通常占据总计算量的60%–80%。在推荐系统中，78%的个性化推荐 将点积作为核心排序指标，用于计算用户向量与商品向量的匹配度；在Transformer架构的LLM中，自注意力机制的矩阵乘法由海量点积构成，以GPT-2为例，点积占总 计算量70%以上，其执行效率直接决定推理性能与能效，尤其在资源受限的边缘端更为关键。
 > RISC-V凭借开源、模块化及可自定义扩展的优势，成为边缘AI处理器的主流架构。通过自定义向量点积指令（vdot），可在处理器流水线中集成专用硬件加速单元，以 极小面积开销换取数倍点积吞吐提升，满足边缘LLM对高性能、低功耗、低成本的需求。“香山”昆明湖V2作为国产高性能RISC-V处理器，具备成熟的向量扩展与自定义指 令接口，为vdot指令的硬件集成提供了理想的架构基础。
 赛题内容
 目标平台：“香山”昆明湖 V2 处理器（国产开源高性能 RISC-V 处理器）。
 技术基础：具备成熟的向量扩展与自定义指令接口。
 核心要求：复用香山昆明湖 V2 现有的向量实现，将 vdot 指令作为向量指令集中新增的自定义指令进行功能单元扩展。
 vdot.vv 指令语义（SEW = 8, VLEN = 128）
 def vdot_vv(vs1, vs2, sew=8)://根据SEW设定，从两个源向量寄存器中各取8个int8数据    result = 0    for i in range(8):    result +=  sign_extend(vs1[i]) * sign_extend(vs2[i])    //结果写入目标向量寄存器vd的第一个元素    vd[0] = result    vd[1..VLEN-1] = 0
 
 阶段1：按照香山操作手册完成香山开发环境的部署
 阶段2：基于昆明湖V2完成设计文档和RTL的实现核基础功能测试
 阶段3：完成香山协同仿真测试和性能延迟评估
