### `LD_BASELINE_001` - Data Cache Miss

## Load Exception Scenario Descriptions

### 场景原则
- 每个异常场景都按 verification-driver 的闭环原则描述：触发条件、初始状态、刺激序列、并发压力、期望观测、失败签名、checker/coverage 和 evidence gap。
- TLB hit/miss 必须显式建模：TLB hit 进入 PMP/PBMT/PMA/DCache/Uncache 分类；TLB miss 应进入 `C_TM` replay/等待，不应伪装成 page fault、PMP fault 或 DCache miss。
- 异常优先级必须和 replay/redirect 分开验证：faulting load 不能继续产生 MSHR、DCache writeback、Uncache TL Get 或目的寄存器写回；load-store violation 属于 recovery/redirect，与 load exception 的最终优先级需要由 ROB/CSR redirect 源码确认。
- 跨边界必须以 fragment 为单位验证：head/tail 各自 translation/protection/cache 结果独立，最终只能有一次精确异常、一次精确 rollback，或一次合法合并写回。

### Exception Taxonomy
| Class | Representative causes | Key distinction |
| --- | --- | --- |
| Translation | TLB miss replay, load page fault, load guest page fault | TLB miss is a replay/progress event; page/guest-page fault is an architectural exception. |
| Protection / permission | PMP pass, PMP fail/deny, TLB/PMA access fault, vector access to NC/MMIO | PMP pass must transparently continue to memory-type/cache handling; PMP fail must kill DCache/Uncache side effects and report load access fault. |
| Alignment / boundary | NC scalar misalign, MMIO misalign, cacheable misalign policy, cross page, cross cache line | Cacheable misalign behavior is implementation-policy-sensitive; NC/MMIO misalign paths are code-evidenced exceptions. |
| Cache / interconnect error | DCache tag error, forward denied, bypass denied, corrupt/hardware error | Must not retire data; access-fault versus hardware-error cause must match code classification. |
| Debug / trigger | breakpoint trigger, debug trigger action | Debug action may route to debug entry instead of ordinary trap; priority needs CSR/trigger evidence. |
| Memory ordering recovery | load-store violation, exception versus RAW rollback | RAW violation causes rollback redirect; interaction with real exception must be checked as a priority cross. |
