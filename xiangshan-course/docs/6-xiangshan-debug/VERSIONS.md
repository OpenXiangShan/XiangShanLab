# 第 6 章 版本基线索引

本文件是本章的版本索引，规则见[课程根目录 README](../../README.md#版本基线)。

## 1. 本章的特殊约定

本章是**具体 bug 的案例分析**，结论与触发它的 RTL 提交绑定，因此**不做版本迁移**：

- 不得把 V2 的 bug 结论套到 V3（多数问题在 V3 已修复）；
- 也不得为了“版本统一”改写成 V3——那会变成另一个 bug、另一份证据；
- 正确做法是每个案例显式记录基线，并写明“仅对该提交成立”。

## 3. 重跑成本

- **不建议迁移**：把 2.2 的案例“迁到 V3”，等于换一个 bug 重新分析，与版本统一无关。
- **新增 V3 案例**：1 次 emu 构建（可复用，verilator 实测约 7–8 分钟）+ 1 次测试程序编译 + 1 次仿真与波形导出。
- **本轮修复的编译成本为 0**：都是补基线声明与索引，不涉及构建或仿真。
