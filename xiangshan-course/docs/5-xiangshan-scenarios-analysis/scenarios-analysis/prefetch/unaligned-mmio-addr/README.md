# 波形文件压缩包

波形文件 `2026-08-26-11-42-52.fst` 保存在一个 7z 分卷归档中：

- `2026-08-26-11-42-52.fst.7z.001`
- `2026-08-26-11-42-52.fst.7z.002`

两个文件缺一不可。请保持文件名不变，并将它们放在同一个目录中；每个分卷均小于 100,000,000 bytes，便于作为普通 Git 文件存储。

## 依赖

需要 7-Zip 命令行工具，命令名为 `7z`。

在 Ubuntu 或 Debian 上安装：

```bash
sudo apt-get install 7zip
```

在 macOS 上可通过 Homebrew 安装：

```bash
brew install sevenzip
```

## 解压

进入这两个分卷所在的目录，仅对第一个分卷执行：

```bash
7z x 2026-08-26-11-42-52.fst.7z.001
```

解压完成后会得到完整的 `2026-08-26-11-42-52.fst` 波形文件。

## 完整性校验（可选）

先检查归档本身：

```bash
7z t 2026-08-26-11-42-52.fst.7z.001
```

解压后的 FST 文件 SHA-256 应为：

```text
bc8cda68d24c71c545e574718552a61a4f779863bc21917538ced46f0c9a3abb
```

在 Linux/macOS 上可以这样校验：

```bash
sha256sum 2026-08-26-11-42-52.fst
```
