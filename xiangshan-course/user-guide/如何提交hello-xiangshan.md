## 作业提交完整流程

请按照以下三个步骤完成学习并提交作业：

### 步骤一：完成学习任务
1. 访问香山课程仓库：[https://github.com/OpenXiangShan/XiangShanLab](https://github.com/OpenXiangShan/XiangShanLab)
2. 学习课程: [香山开发环境总述.md](../docs/课程体系1：操作篇-香山开发环境操作/1.CHN/第一章香山开发环境总述.md)
3. 完成"hello xiangshan"任务
4. 准备任务完成截图（需包含完整的运行结果、打印结果需要有您的个人信息）

### 步骤二：提交GitHub Issue
1. 访问香山课程仓库的Issues页面
2. 点击"New Issue"按钮
3. 选择"作业提交"模板
4. 填写以下信息：

#### 必填信息：
- **您的称呼**：请输入您的姓名
- **您的身份**：选择您的身份
  - 开芯院内部员工
  - 合作企业/高校成员  
  - 香山爱好者（个人学习者）
  - 其他
- **任务完成截图**：请上传hello xiangshan运行成功的完整截图
  - 要求：显示完整的终端窗口，包含命令和输出结果

#### 选填信息：
- **学习心得与反馈**：可分享学习体会、遇到的困难或对课程的建议

#### 确认事项（请勾选）：
- [ ] 我确认截图和输出为我本人完成的学习成果
- [ ] 我同意此提交将公开展示在香山课程社区中（昵称和截图）
- [ ] 我同意开芯院在课程改进中使用我的匿名化反馈（可选）

5. 点击"Submit new issue"提交

### 步骤三：发送邮件确认
1. 获取您提交的Issue链接
   - 格式为：`https://github.com/OpenXiangShan/XiangShanLab/issues/[编号]`
   - 例如：`https://github.com/OpenXiangShan/XiangShanLab/1`

2. 发送邮件至HR邮箱：
   - **收件人**：qinlin@bosc.ac.cn、anxu@bosc.ac.cn
   - **邮件主题**：[香山课程Hello Xiangshan作业提交] - 您的姓名
   - **邮件正文**：
   ```
   我已完成香山课程"hello xiangshan"任务，并已提交作业至GitHub。

   作业Issue链接：[请在此处粘贴您的Issue链接]

   姓名：[您的姓名]
   提交时间：[YYYY-MM-DD]

   期待您的审核！
   ```
## 重要提示

1.  **截图要求**：请确保截图清晰显示完整的命令执行过程和结果输出
2.  **信息真实**：请确保提交的所有信息真实有效
3.  **及时提交**：完成任务后请及时提交，以便我们及时处理
4.  **邮件抄送**：建议同时抄送两个邮箱，确保至少一人收到
